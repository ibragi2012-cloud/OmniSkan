# OmniScan: 👁️

Проект автономного робота-разведчика со сканирующим ИИ-зрением на базе **ESP32-CAM** и **Arduino Uno**. Плата камеры закреплена непосредственно на сервоприводе, выступая в роли активного эгоцентрического сенсора.

## 🚀 Возможности
* **Active AI Scanning:** Камера непрерывно вращается на 180°, сканируя сектор с помощью нейросети **YOLOv8** (80 классов).
* **Target Lock-On:** При обнаружении объекта ИИ фиксирует взгляд сервопривода на цели, рассчитывает вектор ошибки и направляет ПИД-шасси ровера на объект.
* **Ручной HUD-Перехват:** Управление движением с клавиатуры (W,S,A,D) и ручное наведение глаза-камеры (I,O).

## 🔌 Подключение
* `ESP32-CAM 5V/GND` ➡️ Внешний силовой DC-DC 5V ровера (Общий GND с Arduino).
* `ESP32-CAM U0R (RX)` ➡️ Пин `A5 (TX)` Arduino Uno.
* `ESP32-CAM U0T (TX)` ➡️ Пин `A4 (RX)` Arduino Uno.
* `Servo Signal` ➡️ Пин `9` Arduino Uno.

## ⚡ Запуск
1. Прошейте Arduino Uno (ПИД-драйвер, 38400 бод) и ESP32-CAM (скетч MJPEG-моста).
2. Снимите ESP32-CAM с программатора, соберите робота и включите тумблер питания.
3. Подключите ПК к Wi-Fi сети **`NEYMARK_01`** (пароль: `neymark123`).
